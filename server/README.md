# Serveur

Serveur Colyseus du jeu de duel. Il fait autorité : il exécute la simulation de `shared/`, valide les coups et mène les manches. Une fois le client construit, il le sert aussi, sur le même port (2567).

```bash
npm start   # depuis la racine : construit le client et lance ce serveur
```

Voir le `CLAUDE.md` à la racine.
